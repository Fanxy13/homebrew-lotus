## Description
Lotus is a free, open-source start screen and command center for the terminal. Version 3.0 brings it from macOS to Linux – and
shows what is tested where.

What is in it: the start screen and 13 themes, slash commands, an AI terminal (Apple Intelligence, Claude with your own key, or a
local model through Ollama or llama.cpp), an image converter, pets, plugins with a sandbox, a Minecraft server setup, and more.

Install on macOS:
  curl -fsSL https://raw.githubusercontent.com/Fanxy13/homebrew-lotus/main/install.sh | zsh
Install on Linux:
  curl -fsSL https://raw.githubusercontent.com/Fanxy13/homebrew-lotus/main/install.sh | sh
No administrator rights. Windows is in development and not in this release.

Website and docs: https://fanxy13.github.io/homebrew-lotus/
