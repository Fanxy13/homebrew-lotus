Questions

      

        
Does it run on Windows?
Yes, as a beta: a native PowerShell module for Windows 11 (or 10) and Windows Terminal – it runs in the Windows PowerShell 5.1 that Windows 11 comes with (PowerShell 7 works too), so nothing has to be updated first. No WSL, no compatibility layer, no administrator rights. Install it in PowerShell with the line of the Windows tab above. It is tested on every change on GitHub’s Windows machines (PowerShell 7 on x64 and Arm64, Windows PowerShell 5.1 on x64), not yet by people in their own window; the table above says what is tested there.

        
Does Lotus need zsh on Linux?
Lotus' engine is zsh. The install script asks before it installs it and shows the exact command first. Your own shell can stay bash: Lotus loads into zsh and bash alike.

        
Does it need administrator rights?
No. It installs into your home folder. Where a command needs software from your system's package manager, Lotus shows the exact command and asks first – and the system asks for your password itself, in the open. Lotus never reads or stores it.

        
Does Lotus send anything anywhere?
No telemetry. It goes online only for what you ask: the weather, a web search, an update check, the AI you chose. Your files and your clipboard stay on the computer.

        
Do I need an AI account?
No. The AI is optional. Use a local model through Ollama or llama.cpp, an OpenAI-compatible server, Claude with your own key, or on a Mac Apple Intelligence. Keys are kept in the Keychain or your desktop's keyring, never in the repository or in a web page.

        
How do I remove it?
lotus uninstall asks first, then removes the program, its settings, the lines in your shell's startup file and the keys it stored.

        
Where are the settings?
~/.config/lotus – plain text you can read. Updates keep them as they are.
