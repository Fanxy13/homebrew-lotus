Device tools

iOS tools

Type /ios. Lotus detects your iPhone or iPad, checks which tools support it, opens installed apps and downloads official releases. It is a launcher – the tools stay their authors' projects.

Compatibility check

Connected devices are detected in the terminal: /ios devices (with brew install libimobiledevice it also reads the iOS version).

Lotus never bundles these tools. Downloads come from the official GitHub releases or websites shown on each card. Jailbreaking and system tweaks can void warranties or cause data loss – read each project's own instructions first.
