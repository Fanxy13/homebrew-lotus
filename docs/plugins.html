Plugins

Build your own Lotus

A plugin adds commands, tools for the AI and a line under the start screen – written in zsh, Python, Node or anything that runs on a Mac. Make one in a minute, install the ones others made, and share yours.

Start in a minute

  1. Make one

    $ lotus plugin new my-tool

    A working plugin in ~/.config/lotus/plugins/my-tool: a command, a tool for the AI and a start screen line.

  2. Run it

    $ lotus my-tool

    In a new Lotus shell also as /my-tool. Ask /ai to greet someone, and it uses the plugin's tool.

  3. Change it

    $ lotus plugin check my-tool

    Edit its plugin.conf and programs; check says what is wrong and how to fix it.

What a plugin can bring

Commands

command todo = todo.zsh

lotus todo add milk runs todo.zsh add milk. As many commands as it needs – but not one of Lotus' own names.

Tools for the AI

tool add = todo.zsh add

/ai and the web chat use them when they help: "put milk on my list". Lotus checks every value and asks first when the tool changes something.

A start screen line

startup = todo.zsh count

One line under the start screen. It is made in the background, so a slow program never slows down the start.

plugin.conf

One setting per line. The example is the todo plugin.

plugin.conf
# what you see
name        = todo
title       = To-do
version     = 1.0
description = A small to-do list in the terminal

# what it may do: limited (a sandbox) or full
access      = limited
network     = no

# lotus todo …
command todo = todo.zsh

# a tool for the AI, with its parameters
tool add               = todo.zsh add
tool add.level         = act
tool add.description   = Add a to-do to the user's list.
tool add.param text    = text, required, What there is to do

# under the start screen, at most every 60 seconds
startup       = todo.zsh count
startup.every = 60

A tool's program gets its values as arguments and as LOTUS_ARG_<NAME>, prints its answer for the AI and ends with 0 (done), 1 (failed), 2 (wrong arguments) or 3 (the user has to decide). Parameter types: text, int(1,999), enum(a|b|c), path. Every program finds its own data folder in LOTUS_PLUGIN_DATA and the theme's colors in LOTUS_COLOR_KEY and friends.

Limited or full access

limited

The default. The plugin runs in a macOS sandbox: it reads only its own folder and writes only its data folder. No internet unless it says network = yes, no keychain, no controlling other apps, nothing of your files or Lotus' settings – and never the AI's API keys.

full

For plugins that work with Lotus itself or your files. It runs with your rights and can load Lotus' own functions: its settings, colors and look. Lotus asks you before it installs one, and again whenever one of its files changes.

A plugin is code that runs on your Mac. Lotus always shows what a plugin brings and may do before it installs it. Give full access only to plugins from people you trust.

Share it

Put your plugin's folder in a git repository, with its plugin.conf at the top. Anyone can install it:

$ lotus plugin install https://github.com/you/lotus-todo

and gets your newest version with lotus plugin update todo. Lotus is open source under the MIT license – open a pull request to list your plugin in plugins/README.md.

Examples to start from

todo

Limited. A command, three AI tools (add, list, done) and a start screen line; its list lives in its data folder.

github

Limited, with the internet, in Python: stars, forks and the newest release of a repository, and GitHub's zen on the start screen.

hello

Full access: Lotus' own look, your theme and the features that are on.

All plugin commands

CommandWhat it does
lotus pluginYour plugins: what they bring, what they may do, whether they are on
lotus plugin new <name> [full]A working plugin to start from, limited or with full access
lotus plugin check <name>Check its plugin.conf – what is wrong and how to fix it
lotus plugin install <folder or git URL>Install one – it shows what it brings and may do, and asks
lotus plugin info <name>Everything about one plugin
lotus plugin on / off <name>Turn it on or off; its files stay
lotus plugin allow <name>Allow a plugin with full access again after its files changed
lotus plugin update <name>The newest version of a plugin installed from git
lotus plugin remove <name>Delete it and its data (asks first)
lotus features plugins offTurn off all plugins at once
