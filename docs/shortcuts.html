Shortcuts

Faster than typing

A keyboard shortcut that opens Lotus from anywhere, and your own slash commands for the sites, apps and folders you use every day.

Apple Shortcut

⌃⌥L→lotus

Press a key combination anywhere on your Mac and Terminal opens with Lotus.

  1. Add the shortcut

    Add “Open Lotus” to Shortcuts

  2. Pick your keys

    In the Shortcuts app: open “Open Lotus” → the info button (i) → Add Keyboard Shortcut → press e.g. ⌃ ⌥ L.

  3. Allow it once

    The first run asks whether Shortcuts may control Terminal. Choose Allow. If Shortcuts says scripts are turned off: Shortcuts → Settings → Advanced → Allow Running Scripts.

The shortcut has a single action: tell application "Terminal" to do script "lotus". It also shows up in Spotlight and under Services.

Build it in about a minute – the ready-made link will appear here once it is published.

  1. New shortcut

    Open the Shortcuts app and click +. Name it “Open Lotus”.

  2. Add one action

    Search for Run AppleScript and replace its text with:

    tell application "Terminal" to do script "lotus"

    Copying gives you the full script, including activate, so Terminal comes to the front.

Your own commands

Give anything a short name. After that, typing /name opens it.

A website

lotus shortcut add yt https://youtube.com

Then: /yt

A search

lotus shortcut add yts "https://youtube.com/results?search_query={q}"

{q} becomes your words: /yts lofi beats

An app

lotus shortcut add chat Discord

Then: /chat

A folder or file

lotus shortcut add work ~/Documents/Work

Opens it in Finder.

A Lotus command

lotus shortcut add home "/weather Tokyo"

Then: /home

Manage them

/lotus shortcuts

List, run, edit, turn off or delete.

All shortcut commands

CommandWhat it does
lotus shortcut add <name> <target>Add a shortcut. The type is detected: link, app, folder or file, Lotus command
lotus shortcut edit <name> <target>Point it somewhere else
lotus shortcut off <name> / onTurn it off without deleting it
lotus shortcut rm <name>Delete it (asks first)
lotus shortcut listShow all shortcuts

Shortcuts cannot run shell commands – that keeps a typo or a copied snippet from doing something you did not mean. Names of built-in commands like /weather are reserved.
