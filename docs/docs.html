How Lotus works

Lotus 2.0 is a start screen and command center for the macOS terminal. Everything below in one place.

Install

Paste one line into Terminal:

$ curl -fsSL https://raw.githubusercontent.com/Fanxy13/homebrew-lotus/main/install.sh | zsh

Or with Homebrew:

$ brew install Fanxy13/lotus/lotus

Open Lotus with a key combination from anywhere: add the Apple Shortcut, then give it keys in the Shortcuts app (info button, Add Keyboard Shortcut).

First start

The first time Lotus runs, a short setup asks four things – you can change all of them later:

  1. Your name

    Used in the greeting.

  2. A theme

    13 color themes with a preview.

  3. Auto-start

    Show Lotus every time Terminal opens, or only when you type lotus.

  4. Interface language

    English, Deutsch, Français or Español.

Run it again any time with lotus setup. Updating from Lotus 1.x keeps your settings and skips the setup.

Using Lotus

Commands start with a slash and work in every Terminal window. The full list is on the commands page and in the terminal with /lotus cheatsheet.

Forgiving

/weatr → “Did you mean /weather?”. App names, packages and shortcuts are matched the same way.

Links

Paste a link and press Enter – it opens in your browser. open Spotify opens apps.

Clean errors

Missing tools, no internet or a wrong input get a short explanation and a way forward instead of raw shell errors.

Settings

Type /settings. Arrow keys to move, Enter or ←→ to change, v to preview the start screen, q to close.

Configuration file

Everything is stored in ~/.config/lotus/settings.zsh – plain text, one setting per line. Your own logo is ~/.config/lotus/logo.txt. Temporary data (weather, now playing) lives in ~/.cache/lotus.

settings.zsh
# lotus – settings (easier: lotus settings)
LOTUS_NAME='Alex'
LOTUS_THEME='matcha'
LOTUS_STARTUP='1'
LOTUS_WEATHER_LOCATION='Zurich'
LOTUS_AI_PROVIDER='auto'
typeset -gA LOTUS_SHORTCUTS=('yt' 'url|https://youtube.com|on')

AI providers

/ai uses the first provider that works on your Mac. Pick one in /settings, check them with /ai status.

Apple Intelligence

Runs on your Mac – nothing leaves it. Needs macOS 26 or newer, Apple silicon, Apple Intelligence turned on and the Command Line Tools (Lotus builds a small helper once).

Ollama

Local models. Install Ollama, open the app and pull a model, e.g. ollama pull llama3.2.

OpenAI-compatible

Any service with an OpenAI-style API. Set the URL in /settings. The key comes from $LOTUS_AI_KEY or the macOS Keychain (lotus ai key) – never from a file.

/ai command only suggests a command. It never runs it: you choose to put it on the command line or copy it.

Update and uninstall

CommandWhat happens
lotus updateShows the installed and the newest version, then updates. Settings stay untouched.
lotus doctorChecks macOS, zsh, fastfetch, colors, ~/.zshrc and the optional tools.
lotus uninstallAsks first, then removes Lotus, its settings, cache and the lines in ~/.zshrc. Also in /settings.
brew uninstall lotusFor Homebrew installs. Keeps your settings; add --zap to remove them too.

Privacy and security

No accounts, no tracking

Lotus has no server. It only goes online for what you ask: weather (Open-Meteo), updates (GitHub), downloads you confirm.

Nothing runs behind your back

Installs, downloads and deletions are shown first and need a yes. Lotus never runs sudo silently and never stores passwords or Apple ID details.

Checked input

Links must be http or https, package names and city names are validated, and shortcuts cannot run shell commands.

Trusted sources

Apps come from Homebrew Cask, Minecraft servers from Mojang or PaperMC (checksums verified), iOS tools from their official releases.

Troubleshooting

Wrong colors/settings → Color mode → 256 colors.
No logoThe window is too narrow – Lotus switches to the minimal logo, then none. Make the window wider.
/skip does nothingSpotify and Music work directly. Other players need your terminal app in System Settings → Privacy & Security → Accessibility.
Anything elseRun lotus doctor and open an issue on GitHub.
