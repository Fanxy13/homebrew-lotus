How Lotus works

Lotus 2.3 is a start screen and command center for the macOS terminal. Everything below in one place.

Install

Paste one line into Terminal:

$ curl -fsSL https://raw.githubusercontent.com/Fanxy13/homebrew-lotus/main/install.sh | zsh

Or with Homebrew:

$ brew install Fanxy13/lotus/lotus

Open Lotus with a key combination from anywhere: add the Apple Shortcut, then give it keys in the Shortcuts app (info button, Add Keyboard Shortcut).

First start

The first time Lotus runs, a short setup walks through five steps in the Matcha colors, with a small lotus that opens a little more with every step – esc goes back, nothing is saved before Finish, and everything can be changed later:

  1. Welcome

    The interface language: English, Deutsch, Français or Español. The page switches to the language you point at.

  2. You

    Your name, one of 13 themes (the lotus takes the colors of the theme you point at), and whether Lotus shows up in every new Terminal window.

  3. Features

    Which parts of Lotus to turn on – app launcher, Homebrew, web search, weather, AI terminal, music, visualizer, video downloads, iOS tools, Minecraft, Remove BG.

  4. Setup

    Only for what you turned on: your weather city, connecting Claude, the Remove BG model and output folder.

  5. Review

    Everything at a glance, then Back or Finish. On Finish the lotus opens all the way and its pollen writes Hello and your name.

Run it again any time with lotus setup. Updating from Lotus 1.x or 2.x keeps your settings and skips the setup.

Using Lotus

Commands start with a slash and work in every Terminal window. The full list is on the commands page and in the terminal with /lotus cheatsheet.

Forgiving

/weatr → “Did you mean /weather?”. App names, packages and shortcuts are matched the same way.

Links

Paste a link and press Enter – it opens in your browser. open Spotify opens apps.

Clean errors

Missing tools, no internet or a wrong input get a short explanation and a way forward instead of raw shell errors.

Type /settings. Arrow keys to move, Enter or ←→ to change, v to preview the start screen, q to close.

Features

Lotus is made of features you can turn on or off – in the setup, in /settings → Features, or with lotus features. The list comes from data/features.tsv, the same file the website reads.

Off means off

A feature that is off has no command, its settings are hidden, it downloads nothing and it adds nothing to the start of Lotus. Turning off Music also removes now playing from the start screen.

Easy to bring back

Its commands say that it is off and how to turn it on – or turn it on right there. The cheatsheet only shows what is on.

Scriptable

lotus features minecraft off, lotus features bg on. Without a terminal, lotus features prints the list.

Configuration file

Everything is stored in ~/.config/lotus/settings.zsh – plain text, one setting per line. Your own logo is ~/.config/lotus/logo.txt. Temporary data (weather, now playing) lives in ~/.cache/lotus.

settings.zsh
# lotus – settings (easier: lotus settings)
LOTUS_NAME='Alex'
LOTUS_THEME='matcha'
LOTUS_STARTUP='1'
LOTUS_WEATHER_LOCATION='Tokyo'
LOTUS_AI_PROVIDER='auto'
typeset -gA LOTUS_SHORTCUTS=('yt' 'url|https://youtube.com|on')

The AI terminal

Type /ai and the AI terminal opens: a chat you keep typing into – no /ai in front of every message. Ask questions, let it explain code, or let it work in the folder you started it in.

Works on your Mac

It can list, read and search files, create and change files and run commands. Reading inside the folder happens right away; every change and every command is shown first and needs a yes. a allows the rest of the session, n lets you say what to do instead. Never sudo.

Remembers

The conversation stays for an hour after your last message, also for single questions with /ai <question>. When it gets long, older messages become a summary. /ai new or /clear starts fresh.

Thinks first

Claude thinks before it answers, Ollama models with a thinking mode too. Apple Intelligence decides whether a message needs files, plans the steps and checks that it really did them. Set the depth with /effort or in /settings.

Inside the AI terminalWhat it does
/loginConnect Claude: opens the key page, paste the key once
/modelChoose who answers: Apple Intelligence, Claude Opus, Sonnet, Haiku or Fable, an Ollama model, your OpenAI-compatible API
/effortQuick, balanced, thorough or maximum

Providers

/ai uses the first provider that works – or the one you pick with /model or in /settings. /ai status shows what is available.

Claude

The strongest choice for code and longer work. Type /login in the AI terminal (or lotus ai login): Lotus opens the key page, you paste the key once, Lotus checks it and keeps it in the macOS Keychain. You pay Anthropic for what you use.

Apple Intelligence

Runs on your Mac – nothing leaves it, free. Good for questions, texts and small file tasks. Needs macOS 26 or newer, Apple silicon and Apple Intelligence turned on.

Ollama

Local models. Install Ollama, open the app and download a model that can use tools, e.g. ollama pull qwen3.

OpenAI-compatible

Any service with an OpenAI-style API. Set the URL in /settings, the key with lotus ai key openai.

The AI terminal is a small Swift program that Lotus builds once on your Mac (about 15 seconds; needs the Command Line Tools: xcode-select --install). Keys come from the Keychain or $ANTHROPIC_API_KEY / $LOTUS_AI_KEY and are never written to a file. /ai command only suggests a command – it never runs it.

Remove BG

/bg remove photo.jpg removes the background and saves a transparent PNG. It runs on your Mac: no cloud, no upload, no account – after the one-time download it works offline. /bg remove without a path shows a drop zone: drag images from the Finder into it, or press ⏎ to take the image in the clipboard. /bg paste does that directly – a screenshot, “Copy Image” from a browser, or files copied in the Finder. A folder processes every image in it.

Auto

BiRefNet on Apple silicon, BiRefNet Lite on Intel – and a model that is already downloaded always wins, so Auto never downloads a second one on its own. Apple silicon runs on the GPU (PyTorch MPS), with the CPU as fallback.

Installed when you use it

The first /bg remove shows what it needs – a Python environment with PyTorch (about 1 GB, once) and the model – and downloads only after a yes, into ~/.local/share/lotus. Every file is pinned and checked with SHA-256.

Never overwrites

photo.jpg becomes photo_no_bg.png, then _2, _3 … in your output folder: a Lotus folder in Pictures, next to the original, or any folder (/bg output). Full resolution, color profile kept.

Draw what you want to keep

Press r after the AI, or use --edit: a small window with brush, eraser, size, undo, redo, clear, reset, invert and preview. Painted areas always stay; their edges snap to the object.

Clean edges

The model's mask is refined along the edges of the photo, faint specks are removed, and edge colors are rebuilt without the old background – no halos around hair.

Clear errors

If something fails you see what happened, why and what to try, with an error ID such as BG-004. The details are in /lotus log. A failing GPU or model comes with an offer to use the CPU or another model.

Formats: PNG, JPG, WebP, HEIC, AVIF, TIFF, BMP, GIF. /bg models downloads, checks and removes models. BiRefNet (Peng Zheng et al.) and InSPyReNet (Taehun Kim et al.) are MIT licensed – see THIRD_PARTY.md.

Pets

Up to three little pixel pets live in your terminal. Type a pet's name and it answers – with Apple Intelligence on your Mac, in your language and with its own personality. /pets adopts, renames and feeds them; /help lets your pet find the right command, and in /ai it sits in the welcome box and its face is the spinner. Everything about them – and the prompt to make your own – is on the Pets page.

CommandWhat it does
/petsYour pets: adopt, talk, feed, rename, personality, say goodbye, settings
mochi · mochi how was your day?A chat with a pet (⏎ on an empty line ends it) · one answer
/feed mochiFeed a pet – they get hungry after half a day
/help · /help allYour pet asks what you need and shows the commands · every command
lotus pets add [file]Add your own kind of pet (from the clipboard or a file)

Adopted pets are in ~/.config/lotus/pets.tsv, your own kinds in ~/.config/lotus/pets/, hunger and what they remember in ~/.local/state/lotus/. A pet's name only calls it when no command, alias or function has that name.

Log

/lotus log shows what Lotus did – commands, settings changes, downloads, installs, the AI's tool use, Remove BG stages and every error – with the time and the part of Lotus it came from.

CommandWhat it does
/lotus logThe viewer: f filter by level, / search, ⏎ details, l live, y copy, c clear
/lotus log level debugHow much is written: off, warn, info (normal), debug (detailed), trace (everything)
/lotus log live · lotus -V <command>Follow new lines · print the log while one command runs
/lotus log clear · /lotus log pathDelete the log · where the file is

The file is ~/.local/state/lotus/lotus.log, rotated at 1 MB and trimmed after the retention time (7 days by default). Keys, tokens and passwords are masked, your home folder is written as ~, and nothing leaves your Mac.

Update and uninstall

CommandWhat happens
lotus updateShows the installed and the newest version, then updates. Settings stay untouched.
lotus doctorChecks macOS, zsh, fastfetch, colors, ~/.zshrc, the optional tools, Remove BG (Python, PyTorch, MPS, models, output folder, editor), the log and the features.
lotus uninstallAsks first, then removes Lotus, its settings, AI memory and saved AI keys, the log, the Remove BG models, cache and the lines in ~/.zshrc. Also in /settings.
brew uninstall lotusFor Homebrew installs. Keeps your settings; add --zap to remove them too.

Privacy and security

No accounts, no tracking

Lotus has no server. It only goes online for what you ask: weather (Open-Meteo), updates (GitHub), downloads you confirm.

Nothing runs behind your back

Installs, downloads and deletions are shown first and need a yes – the AI's file changes and commands too. Lotus never runs sudo and never stores passwords or Apple ID details.

Checked input

Links must be http or https, package names and city names are validated, and shortcuts cannot run shell commands.

Trusted sources

Apps come from Homebrew Cask, Minecraft servers from Mojang or PaperMC (checksums verified), iOS tools from their official releases, Remove BG models from their authors – pinned and checked with SHA-256.

Images stay on your Mac

Remove BG reads and writes local files only. No cloud API, no upload; dropped paths are never run as commands.

Pets talk on your Mac

Pets think with Apple Intelligence on the device; what you tell them and what they remember stays in ~/.local/state/lotus. A pet file is only read as data – its drawings keep plain ASCII and block characters.

Troubleshooting

ProblemFix
lotus: command not foundOpen a new Terminal window, or run exec zsh.
Wrong colors/settings → Color mode → 256 colors.
No logoThe window is too narrow – Lotus switches to the minimal logo, then none. Make the window wider.
/skip does nothingSpotify and Music work directly. Other players need your terminal app in System Settings → Privacy & Security → Accessibility.
A command says its feature is offlotus features or /settings → Features.
Remove BG failsThe error screen shows an ID and what to try. Details: /lotus log. Checks: lotus doctor.
Anything elseRun lotus doctor, look at /lotus log, and open an issue on GitHub.
